# dome-lens

スマホの画面に透明なドーム（レジンやアクリルの半球・球冠）を乗せ、屈折を逆算して
「映像がドームの表面に張り付いて見える」ように表示する実験アプリ。

## 仕組み

- ドーム表面の各点について、目からの光線を屈折させて画素面に着く位置を求める
  （表面 → ドーム内部 → 底面の層 → カバーガラス → 画素）。
- その対応をメッシュにして WebGL で描くと、各画素に「そこが見えるドーム表面の点」の色が出る。
- 目の位置はフロントカメラ（MediaPipe Face Landmarker の虹彩ランドマーク）で推定する。
  虹彩の直径（約 11.7mm）を物差しにして距離を出す。

## 使い方

1. ドームを画面に置く（間に水を一滴挟むと縁の全反射が減る）。
2. 「位置合わせ」で黄色い円をドームの縁に合わせる。
3. 「ドームと素材」で直径・高さ・屈折率などを設定。
4. カメラ追跡：カメラ位置（ドーム中心から見たフロントカメラの位置）を設定し、
   定規で測った距離で「距離を校正」する。

## 開発

```sh
npm install
npm run dev
npm run build
```

`main` に push すると GitHub Actions が GitHub Pages に公開する
（リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく）。
