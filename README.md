# dome-lens

スマホの画面に透明なドーム（レジンやアクリル、ガラスの半球・球冠）を乗せ、屈折を逆算して、
ドームが「薄いガラス球」で、その中に小球が浮かんでいるように見せる実験アプリ。

公開先：https://msonrm.github.io/dome-lens/

## 仕組み

- ドーム表面の各点について、目からの光線が実物のドームで屈折して画面のどの画素に届くかを
  頂点シェーダで計算する（表面 → ドーム → 底面の層 → カバーガラス → 画素）。
- 色は、目からの視線をまっすぐ（実物のドームのレンズ効果を打ち消して）仮想のガラス球の中へ進め、
  小球か、球の下半分の内壁に当てて決める。画面は球の中心の高さにあるとみなす。
- 傾きセンサーと方位で、小球は重力に対して水平を保ち、光は部屋に固定される。

## 小球の模様

- 経緯線 / チェッカー / 無地（陶器）
- チューリングパターン（球面上の Gray-Scott 反応拡散。キューブスフィアの格子で継ぎ目なし）
- 鏡面球（インカメラの映像の映り込み）
- 天球（東京から見た太陽・月・惑星とアスペクト。astronomy-engine で計算）

## 使い方

1. ドームを画面に置く（間に水を一滴挟むと縁の全反射が減る）。ドームなしなら屈折率を 1.00 に。
2. 「位置合わせ」で黄色い円をドームの縁に合わせる。
3. 「ドームと素材」で直径・高さ・屈折率などを設定。

## 開発

```sh
npm install
npm run dev
npm run build
```

`main` に push すると GitHub Actions が GitHub Pages に公開する。
以前の表面モード（顔追跡、眼球、水準器など）は `archive/surface-mode` ブランチに残してある。
